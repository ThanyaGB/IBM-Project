# Core — everything below is free and required to run the bot end to end.
flask>=3.0.3
python-dotenv>=1.0.1
requests>=2.32.3

# Answer generation. Gemini is used on its free tier; Ollama (local, also free)
# is the documented alternative for privacy-sensitive deployments.  Either one
# alone is enough, and with neither the bot degrades to the localised
# "consult your health worker" reply rather than failing to boot.
google-genai>=1.5.0

# Optional statistical language pass. The primary detector is script- and
# lexicon-based and needs no dependency; this only helps for long, ambiguous
# Latin-script text.
langdetect>=1.0.9

# Card rendering fallback. The primary renderer is headless Chromium (Chrome or
# Edge, already present on most machines), which is the only one that shapes
# Devanagari and Kannada correctly. Pillow cannot, so it renders English only.
Pillow>=10.4.0

# Voice replies (default-on). edge-tts is free and needs no API key; it also
# needs ffmpeg on PATH, because WhatsApp only accepts audio/ogg with the Opus
# codec. Without it the bot replies in text only and /health reports
# "voice_replies" as degraded.
edge-tts>=6.1.0

# Tests and evaluation
